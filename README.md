# Parcel / Flow

A delivery-service frontend concept and computer architecture project. The site demonstrates parcel tracking, delivery planning, business sending, a local delivery network, and a technical explainer for the simulated processor.

## Run locally

```sh
npm ci
npm run dev
```

## Demo limitations

Parcel / Flow is a student project and service concept. Tracking updates are samples; the delivery planner creates only a browser-side preview. Live carrier tracking, rates, service coverage, bookings, pickup scheduling, and payments are not connected.
